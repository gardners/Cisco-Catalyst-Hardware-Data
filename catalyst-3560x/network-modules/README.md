# Cisco Catalyst 3560-X / 3750-X network modules

This directory records original Cisco removable uplink hardware. Interfaces, measurements and images are documented independently of replacement-board projects.

- [C3KX-NM-10G](C3KX-NM-10G/README.md) -- dual 10GbE SFP+ / four SFP network module, BCM8727.

Other compatible slot-family modules reported by Cisco: `C3KX-NM-1G`, `C3KX-NM-10GT`, and `C3KX-SM-10G`; shared electrical pinouts are **not verified**.
