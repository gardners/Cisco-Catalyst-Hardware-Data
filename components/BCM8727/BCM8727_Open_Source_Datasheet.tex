\section{Management and status}
\subsection{MDIO and PHY identification}
Clause 45 device addressing and MMD accesses are supported \m{P}. Terasic U6 shows MDC2/MDIO2, optional dual-device MDC1/MDIO1, and hardware PHY address straps \m{R}. Linux's \texttt{bcm87xx} driver identifies BCM8727 using PHY ID \texttt{0x0143bff0} read from PHYXS (MMD 4) identity fields \m{S}\src{L}. This ID is a driver-match constant, not a proof that all suffix revisions use it.

\subsection{Boot, NVM and optics-control pins}
The device exposes SPI ROM clocks, data and chip select per channel; serial boot enable at H10; a configurable BSC/two-wire interface, and per-channel optics control/status. The presence of these pins does not establish a mandatory external ROM image or boot algorithm. The public product brief does not provide an ordered register initialisation sequence, strap truth table, default PHY addresses, nor firmware image format. Each is \unk.
\section{Package and BGA naming}
Broadcom specifies 324 balls in a 19 x 19 mm body with 1 mm pitch \m{P}. The following index assumes a full 18-by-18 grid with row labels \texttt{A B C D E F G H J K L M N P R T U V} and columns 1--18 \m{I}; all 324 positions are indexed. Terasic provides names for \textbf{110} positions \m{R}. The remaining \textbf{214} positions are uncharacterised \unk, including potentially critical supply and ground balls. \textbf{Do not design a footprint from this index without the manufacturer's package mechanical drawing and verified A1 orientation.}
